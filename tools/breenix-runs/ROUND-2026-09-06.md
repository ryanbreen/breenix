the brief's explicit exception: copy under Contents/Resources before signing,
and resolve that packaged location in StageCatalog for app launches. Bare CLI
and XCTest retain Bundle.module. No generated accessor is edited.

resolved paths. The library XCTest asserts those paths belong to the app,
which excludes accidental success through the absolute build fallback.
