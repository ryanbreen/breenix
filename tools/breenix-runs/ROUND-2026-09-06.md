## Item 1: automatic import

Crash fix commit: d7a4645e. Six gate scripts now source the nonfatal helper and
call it after their local classification. The helper writes run-inspector.json
with UUID identity, gate argv, arch/profile, verdict/exit status, start/end,
and available serial/capture paths. Importer retains that authority; a
relocated sidecar keeps its run ID. Attributed results project as attributed.
Loose serial inference remains unchanged. Local Inspector launches opt out of
hook import to avoid duplicate wrapper records.

The helper resolves BREENIX_RUNS_BIN, then PATH, then the repo's
tools/breenix-runs/.build/release/breenix-runs. It retains failure diagnostics in
inspector-import.log. Python bounds the child wait (15 seconds by default,
configurable up to 60), kills only its recorded child group on timeout, and
reaps it. Sourcing installs no traps/options. BREENIX_RUNS_NO_IMPORT=1 skips
metadata/import. Missing start time or serial evidence skips preflight input.
Gate sources/traps retain their existing printed classification and exits;
elapsed-time reports naturally include time spent in post-verdict capture.

RunStore accepts BREENIX_RUNS_STORE for isolation, serializes index writers
with flock, and uses unique temporary filenames. Gate facts readers preserve
sidecar filenames/line numbers and deduplicate repeated gate records.
Linux direct gates can retain metadata when the Mac importer is unavailable;
a Linux-to-Mac background collector is not implemented in this concern.
