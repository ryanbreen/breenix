- Each boot: `scripts/772-dispatch-boot.sh` (unmodified) — guest launched with
  the QEMU gdbstub open (`-s`), driver polls serial for `USERSPACE TEST
  COMPLETE` + `TEST_TALLY:`, connects GDB while the guest is still running,
  reads each `DISPATCH_*` counter symbol present in that boot's own ELF (via
  `nm`) from the per-CPU slot 0 — 39 symbols this branch's binary carries
  (`counter_symbols.txt`, identical count on both arms since neither feature
  flag adds or removes a `DISPATCH_*` static), only then kills the guest (by
  PID tree, R84), scores the boot with `scripts/x86-gate-verdict.sh
  EXPECTED_EXITS=10`, and emits `census.json` via
  `scripts/772-dispatch-census.py`.

  deps were already compiled from a prior slot's build cache on this VM).
- `markers_found=1 gdb_ok=1` on all 6/6 boots — 0 boots had a GDB counter-read
  failure, 0 unattributed (no boot reached the timeout without the completion
  markers, no boot's GDB dump failed to produce
  `DISPATCH_KERNEL_RESTORE_TOTAL_CPU0`).
- Serials + `gdbcmd.txt` + `counter_symbols.txt` + `gdb_output.txt` +
