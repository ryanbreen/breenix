## What the fix commit says (293299993f3e581b06f7006fb1bb5cb46b320ea7)

> scripts: drop breenix_runner.py's host-wide QEMU preflight pkill (#854)
>
> BreenixRunner.start() ran `subprocess.run(["pkill", "-f",
> "qemu-system-x86_64"], ...)` as a preflight before launching its own QEMU
> child -- a bare host-wide pattern match with no distinguishing marker, so
> it could kill a DIFFERENT, concurrent x86 gate's own still-running
> qemu-system-x86_64 process, not only a leftover from a crashed earlier run
> of this runner. Same hazard class as #829/#849; scripts/ci/ring3_check.sh
> (one of #849's own ten fixed scripts, and this runner's own caller)
> already removed its duplicate of this exact line and pointed here.
>
> Fix matches the shape #829/#849 already established for this runner:
> drop the preflight outright. This runner's own QEMU child is already
> PID-scoped -- `self.process` is the `subprocess.Popen` this invocation
> itself started, reclaimed by PID via `self.process.terminate()`/`.kill()`
> in `stop()` -- so the preflight had no leftover of this runner's own to
> legitimately reach. ring3_check.sh's own comment, which disclosed the
> live hazard one layer down and pointed at #854, is updated to record that
> this round closed it.
>
> tests/qemu_kill_by_name_structure.rs's own module doc still describes
> this runner as an example of a shape its `.sh`-only walk cannot reach;
> that .rs file could not be edited in this round (Edit on it was denied by
> this session's own Fable no-source-edits guard, and the round's own scope
> cap disallows dispatching the edit to a subagent), so its now-partially-
> stale prose is left as-is rather than forced through -- disclosed here,
> not silently absorbed. Proof: `scripts/run-structure-tests.sh
> qemu_kill_by_name_structure` still passes 2/2 (the ring3_check.sh comment
> lines are excluded by the ratchet's own comment-skip, so no new violation
> is introduced); a literal `subprocess.run(["pkill", ...])` no longer
> greps out of breenix_runner.py.

Files touched: `scripts/breenix_runner.py` (drops the `pkill -f
