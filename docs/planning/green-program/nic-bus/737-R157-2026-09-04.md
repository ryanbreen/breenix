### F5 — the oracle now has a termination argument, not a window ceiling

`MAX_WINDOWS = 12` bounds the window count. It does not bound run time: a
stalled clock makes each window measure `elapsed = 0 < MIN_WINDOW_MS`, the
escalation multiplies the spin by 8 each pass, and window 12 alone would spin
`10_000_000 * 8^11` register-only iterations.

Three bounds replace the false rationale, covering 3 of 3 clock behaviours:

| clock behaviour | bound that fires | cost before it fires |
|---|---|---|
| stopped | `STALLED_WINDOWS` — two consecutive windows with `elapsed_ms == 0` | 2 windows, `10M + 80M` passes |
| advances, but no window reaches `MIN_WINDOW_MS` | `TOTAL_BUDGET_MS` = 30 s run-total, read from the same CLOCK_MONOTONIC, checked between windows | 30 s |
| either | `MAX_SPIN_ITERATIONS` = 64x base — escalation stops there | one window at 64x base, between two budget checks |

Whichever bound fires is printed on a new line, so a truncated run says so
rather than looking like a healthy one. `MAX_WINDOWS` keeps its value and is
documented as what it is.
