## 2. The classifier

One function, `classify_serial`, reached by both modes:

* `run-aarch64-testing-profile-boot-test.sh [N]` builds the soft-float
  `--features testing` kernel, runs the #528 no-NEON guard on it, boots it N
  times, and scores each serial.
* `run-aarch64-testing-profile-boot-test.sh --classify F...` scores serials that
  already exist, with the same function, so a serial committed as evidence is
  read back by the code that scored it live.

Per boot it prints one verdict line carrying 13 counters:

```
marker= loaded= lockup= stalls_before_lockup= ext2_stalls= kernel_panic=
wedge_fail= strand_first= el1_abort= userspace_panic= userspace_abort=
boot_tests_fail= init_oracle=
```

**The 9 red terms.** `loader-marker-missing`, `loaded-line-missing`,
`unattributed-lockup`, `kernel-panic`, `block-wedge-fail`, `strand-first`,
`el1-abort`, `boot-tests-failure-marker`, `init-oracle-marker-in-testing-profile`.

**Counted, not scored.** Userspace panics and EL0 aborts. The userspace test
catalog deliberately faults (the fcntl/nonblock/pipe2 negative tests), so a
count is the honest treatment; a panic inside the kernel, or an abort taken at
EL1, is a red.

**Lockups are attributed, not merely detected.** A boot carrying a lockup dump
is scored either

* `728-signature` — at least 1 `EXT2_LOCK_SPIN_STALL` line appears *before* the
  first lockup dump. That is the open #728 ext2 read-park livelock: reported in
  the verdict, and not this gate's red; or
* `UNATTRIBUTED` — a lockup with 0 preceding stall lines. A red.

Attribution compares line numbers (`awk -v l="$LOCKUP_LN" '$1 < l'`), not mere
presence: a stall printed after the dump does not explain the dump.

**Two markers this profile cannot emit.** `boot_continuation` returns before
`launch_init_from_elf` under `#[cfg(feature = "testing")]`, so the profile
launches no init and compiles no boot_tests suite. Init's
`[BLOCK_EINTR_ORACLE:` marker and any `[BOOT_TESTS:FAIL` line must therefore be
absent; either appearing means the profile split moved and the gate is scoring a
different kernel than it claims to. Both are red terms.
