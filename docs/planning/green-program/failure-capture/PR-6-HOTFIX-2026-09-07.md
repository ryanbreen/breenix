# PR-6 QMP backstop Linux hotfix — 2026-09-07

## Cause and scope

Missing `socat` made `forensic-capture.sh` exit before QMP; the backstop swallowed that exit and mislabeled the absent core `qmp_timeout`.
The operator supplied the confirmed beast baseline at `e87f19d2`: 13 passed,
2 failed in 0.45s, and this direct capture evidence (not re-diagnosed this round):

```text
$ bash scripts/forensic-capture.sh --qmp /nonexistent --output-dir /tmp/fctest
[07:25:06] ERROR: socat not found. Install with: brew install socat
```

Code commit: `b9b7529e33bdfd8496c645bdbce61453543f8ada`, pushed to
`origin/hotfix/qmp-backstop-suite-linux` and fast-forwarded into
`/root/breenix-hotfix` before Linux verification.

Only the backstop library and its structure suite changed in that commit.
The dependency check follows budget and socket validation, prints
`capture=partial:reason=qmp_tool_missing:core=-:decoded_events=-:dump_ms=<elapsed>`,
and returns before launching the forensic child. Header comments explain why.
The two affected tests check tool availability and print the branch taken.
The tool-present assertions and the missing-socket/invalid-budget sub-cases
retain their previous text. The missing-tool hang branch also checks that
no QMP command was sent. `scripts/forensic-capture.sh` was read but not edited;
its platform-specific error suggestion is unchanged. No additional Linux
behavioral defect surfaced in the targeted suite.
