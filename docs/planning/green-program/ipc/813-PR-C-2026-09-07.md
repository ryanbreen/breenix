The source chain in `timer960-rca-source.txt` explains the starvation window. `kernel/src/main.rs` makes the current boot context `swapper/0`, registers it as idle, and later calls the timer-wake oracle directly. `Scheduler::schedule` deliberately excludes idle from runnable requeue and selects it only after runnable queues are exhausted.
