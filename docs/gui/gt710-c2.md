# C2: bounded GPC down and back up

K1 permits this single diagnostic at the current voltage, below or at POST.
The `gt710_clock_probe` kernel adds `/proc/gt710-clock`: reads report a fresh
C1 hardware decode; privileged writes accept `gpc KHZ` between 540000 and
the measured POST clock (which this diagnostic requires to be 810000).
Other domain names and requests above POST are refused before programming.
A failed set latches the control closed for the remainder of the boot.

The userspace probe waits for production GK208 CAPS and catalogue warm-up.
It reads GPC, runs three C1 core trials, writes 540000, runs three more,
writes 810000, runs three more, then emits `GT710_C2_DONE`. Each trial
keeps C1's 200 full-screen 2560x1600 SOLID shader draws, 819200000 fragments,
one submission, and one final WAIT timed with CLOCK_MONOTONIC. Trial numbers
1-3, 4-6 and 7-9 name POST, low, and restored windows. A first low trial
under 900000000 ns aborts immediately. No memory benchmark or suite runs.

## Source and write boundary

Individually checked MIT nouveau files at Linux v6.8
`e8f897f4afef0031fe618a8e94127a0934896aba`:

- `nvkm/subdev/clk/gk104.c:222-335`: divider path first; prefer the PLL only
  when its integer result is closer. An exact divider wins ties.
- `gk104.c:356-473`: index 0 programs its divider (when selected), switches
  the GPC source off its PLL, disables PLL sync/enable, programs coefficients
  and waits for lock if selected, then returns GPC to the PLL if selected.
  Nouveau's final-divider stage excludes index 0; C2 requires POST's final
  GPC divider to remain unity. C2 visits index 0.
- `nvkm/subdev/clk/pllgt215.c:31-100`: nonfractional P/N/M calculation.
- `nvkm/subdev/bios/pll.c:81-107,142-159,352-365`: bounded BIT C/v40 GPC
  table decoding. Runtime PLL reference comes from C1's register reader.

Notices are retained in `c2.rs`, the C test oracle and `THIRD_PARTY_NOTICES`.
The C oracle preserves nouveau's calculation with host declarations and
explicit signed casts replacing its kernel macros. Coefficient vectors use
810000 and 540000 requests with 810000 and 1620000 reference clocks; these
are host inputs, not claims about the hardware's PLL reference. The actual
reference is read on the diagnostic boot.

The controller can write only 0x137000, 0x137004, bit 0 of 0x137100,
0x137160 and the GPC-divider field of 0x1371d0. The write-address assertion
in `tests/gt710_c2_test.rs` checks this boundary. The native
resource owner serializes programming; the probe's last WAIT has completed
before each write. Hardware source/PLL polls retain the MIT two-second bound
with interrupts enabled. A failure returns without a retry or rollback boot.

## Evidence and stopping

`GT710_CLOCK_SET` reports domain, request, independent hardware readback,
status and the integer PLL step. `GT710_CLOCK_SET_RAW` retains the C1
snapshot used for readback. Divider results at both requested frequencies
are exact on the C1 source snapshot; no register write or computed plan is
accepted as readback evidence.

Watch live from the boot host. Stop this lane's ID through `metal-run stop`
at a set failure, readback difference greater than `step_khz`, trap/fault,
the first low trial below 900 ms, or `GT710_C2_DONE`. One capture can show
reversibility; K1's repeatability requirement remains for a coordinator-
authorized later boot. No PR, merge or persistent install is part of C2.
