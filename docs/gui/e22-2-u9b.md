The ABI allocates `DISPLAY_OUTPUT_PERTURB = 35` and raises LAST to 35. The
shared dispatcher refuses its arm on backends 4/5 and on ARM. On backend 6,
the next matching pinned checkpoint saves the latched output method list and
submits six-bit static 2x2 dithering through the core channel. It counts the
reserved one-shot after the enabling method has latched. The normal CRC
collector then observes that output configuration. A target of 0 matches any
resource; a nonzero target matches that resource.

DISARM_ALL clears the arm and restores the prior dithering method through a
bounded UPDATE, then compares the latched method list with the saved list.
The saved state survives partial publication and restoration errors. A pending
flip retains its notifier and receipt identity: restoration reports an error
and retains the state for a retry after ordinary flip completion. The native
session serializes these operations. The collector and explicit restoration
reuse the existing UPDATE publication and completion implementation.
