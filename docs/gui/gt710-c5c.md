## Offline decode and interpreter support

Check-first commit: `223cb156`. Decode commit: `ec699206`.
The [full opcode/payload listing](gt710-c5c-init-scripts.txt) prints each opcode
address, its eight alternative values and the selected writes. The
[structured decode](gt710-c5c-init-scripts.json) preserves those fields.
The complete installed ROM remains private; its SHA-256 is
`560026acd8fe588e0fde898f0b542bb9aac914f4da4b45ed7017bd90de5a8294`.

RAMMAP is at `0x7259`; its header points to the three u32 script pointers at
`0x741a`. BIT M specifies eight groups. Strap 1 maps through M0203 to group 1.

| RAMMAP mode | Script | Opcode sequence | Selected register writes |
|---|---|---|---:|
| 0 | `0x9eff` | `8f, 8f, 8f, 71` | 8 |
| 1 | `0xa015` | `8f, 8f, 8f, 8f, 71` | 8 |
| 2 | `0xa132` | `8f, 8f, 8f, 8f, 71` | 8 |

The existing interpreter is `kernel/src/gpu/gk208/modeset.rs`, already used by
board display scripts. Before C5c it supported DONE (`71`), but lacked
RAM_RESTRICT_ZM_REG_GROUP (`8f`), and its register range admitted display MMIO.
C5c adds `8f` to that interpreter with a separate RAM decode context. For each
register, it consumes the group alternatives, writes the selected group, then
increments the register by the encoded stride. An unmatched index emits no
write and still consumes the payload, following nouveau. Display callers keep
their existing register range; the RAM route admits `0x110000..0x120000`.

The strap-derived restriction index is cached for decoding, including index 0.
No PEXTDEV_BOOT0 read occurs per RAM-restriction opcode. This follows the caching
warning in MIT nouveau `bios/init.c:439-458`.

## Initialization sequence

`kernel/src/gpu/gk208/ram_init.rs` follows nouveau's load-time initializer:

1. Read `0x10f65c & 0xf0`.
2. For each script index except that saved index, mask the index into bits 7:4
   and execute the decoded script.
3. Restore bits 7:4 with a masked write, preserving the other bits as read then.
4. Mask `0x10f584` with `0x11000000`, data 0.
5. Write `0xffffffff` to `0x10ecc0`.
6. Set bit 4 of `0x10f160`.

Source: [MIT nouveau ramgk104.c:1424-1437](https://github.com/torvalds/linux/blob/e8f897f4afef0031fe618a8e94127a0934896aba/drivers/gpu/drm/nouveau/nvkm/subdev/fb/ramgk104.c#L1424).
The initializer's training call takes the default return-0 branch for DDR3,
with no training register writes (`ramgk104.c:1383-1389`). This step sends no
memx command and makes no memory reclock request.

The diagnostic uses the unchanged C4 PMU loader and firmware, then RAM init,
then the existing three core and three GPC benchmark trials. It records

readbacks, the independent GPC counter and temperatures. Fault, temperature
at least 85 C or changed memory readback stops further RAM writes. Write echoes
are observations, with no equality refusal; no benchmark-time threshold or
