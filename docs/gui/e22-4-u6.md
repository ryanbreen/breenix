# E22 22.4-u6: captures and generation markers

The unit adds `libs/libuitest/src/capture.rs`. Window capture passes the frame and tree arena destinations to one CAPTURE call. The kernel's existing front-buffer and tree-page pins span those copies; there is no later MAP_TREE read. The arena keeps both slots writing until the syscall returns and publishes the captured commit identity with their payloads. A syscall refusal leaves partial evidence. Screen capture reads directly into the screen slot and validates the returned observation through `libbreenix::window::validate_scanout_observation`, with the caller's required plain or composed kind. It checks the returned serial and retains the observation. The v2 window list uses its documented 16 entries of 32 bytes. Surface readback writes directly into the frame slot; authored CPU surfaces use the same slot with commit id 0 and no tree.

The test app draws eight fixed marker columns through its GPU surface batch, extending through its 200 rows, over a literal background. RGB carries the version tag, little-endian commit ordinal and producer tid, plus an FNV-1a checksum; X bytes are opaque. The checksum detects damaged encodings; equality of the decoded pair across rows detects valid but mixed generations. Its root node is NUL-terminated UTF-8 JSON using the plan's node fields, with commit and producer in `value`. BreenGL's small `write_tree` method writes that serialization into the acquired buffer's page before commit. The app asserts that its first ordinal equals the returned commit id. The pure judge requires the row markers and decoded root value to agree with that returned id.

The replaced guest bodies are `frames/window-capture`, `frames/screen-capture`, `frames/capture-commits`, and `runner/inner-expected-failure`. The window case checks the complete fill and marker pattern as well as tree coupling. The kiosk screen case checks the complete 320x200 window at its (0,0) position and its observation identity. The desktop case requires the two app windows' commit identities in the observation. The inner case compares clean and planted CPU surfaces through the real engine and inner executor; the fault must return `PixelMismatch`, operation `marker`, and exactly `first=12,2 got=#182031 want=#182030`.
