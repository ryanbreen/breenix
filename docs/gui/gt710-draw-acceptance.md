# GT 710 draw acceptance records

The producer uploads the image rows in the existing network artifact. Serial carries `GT710_DRAW_BULK <length> <sha256>`, the byte length and lowercase SHA-256 of the concatenated draw rows, as well as the overall `GT710_BULK` anchor. Image rows must not appear on serial. Each newline-terminated ASCII row is `GT710_DRAW_IMAGE <case> <poison> <offset> <hex>`: offsets are decimal byte offsets, poison is 85 or 170, and for the five draw cases, lowercase hex carries 256 bytes except for the final chunk. Cases appear in order `triangle`, `vertex-control`, `after-vertex`, `fragment-control`, `after-fragment`, `present`, each with poison 85 then 170. Every image is complete under each poison. The first five images are the 64×64 pitch-linear BGRA target in `provenance/gt710-triangle.json`; `present` is the complete pitch-by-height scanout including padding. For `present`, the offset is instead the decimal row number and the last field is comma-separated hexadecimal `count:word` runs, where each word has eight digits and each row expands to exactly one pitch. The upload limit is 2 MiB.

`GT710_DRAW` is a single JSON object with `schema: 1`, `class_id: 41367`, `error: null`, `trap_registers: [4194560,4194568,4194576,4194584]`, and zero `trap_before` and `trap_after` arrays. `readbacks` contains one object per image in row order, with `case`, `poison`, `bytes`, and `sha256` over the decoded bytes. `releases` contains five objects, in draw case order, each with aligned nonzero `target`, positive `epoch`, nonzero 32-bit `nonce`, matching `observed_epoch` and `observed`, and `consumed` and `accepted` true. Epoch/nonce pairs must be unique.

The clean triangle and both clean draws following controls must match the oracle's whole-image coverage hash, preserve every background byte, and match every literal sample exactly. Each shader control must fail at least one literal. Both poison read-backs must be identical and each digest must match the complete bytes. These checks do not claim every covered colour byte is an independent literal.

`GT710_PRESENT` is a single JSON object with `schema: 1`, `width`, `height`, byte `pitch`, `background` as a little-endian 32-bit pixel, rectangle origin `x`, `y`, `second_address`, `active_address`, `head`, `active_register`, `active_value`, `firmware_writes`, and `epoch` and `nonce` of the last clean draw. The second address must equal the second distinct surface in `GT710_MEMORY`; the active register must be 0x640460 plus head times 0x300 and its value must equal the second address shifted right by eight. The active address must equal the second address, and firmware writes must be zero. The complete scanout read-back must equal the last clean target in the 64×64 rectangle and the background everywhere else, including pitch padding.
