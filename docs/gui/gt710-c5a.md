# Offline DDR3 calculation

The decoder in `scripts/metal/gt710_memx.py` follows the pinned MIT nouveau
v6.8 BIOS table layouts, DDR3 calculation, ramfuc ordering and PMU memx packing.
The per-file source hashes and licenses are in
[gt710-c5a-sources.json](provenance/gt710-c5a-sources.json) and
`THIRD_PARTY_NOTICES`.

The kernel calculator in `memx.rs` reads runtime tables and live register
state. Host checks build synthetic BIT, M0203, RAMMAP, timing, PLL and GPIO
tables using `tests/gt710_synthetic.py`; compare the independent Python model
and MIT C arithmetic with the emitted kernel stream; and cover transport
ownership, bounded waits and packet ordering.

Card-specific table decodes, generated scripts and the original ROM capture
remain in private run evidence. K9 removes the former raw ROM fixture and
public table/script decodes; the stacked PR uses a squash merge.
