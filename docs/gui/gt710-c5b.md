# Live DDR3 calculation inputs

`memx_inputs.rs` captures the register inputs to the runtime DDR3 calculator.
The read set follows the MIT sources recorded in
[gt710-c5a-sources.json](provenance/gt710-c5a-sources.json).
Private diagnostic captures retain the card-specific values and offline
comparison streams. These captures are separate from production acceptance.

Host checks use generated synthetic tables and registers, change timing and
mode-register inputs between EXECs, and compare each resulting stream with
the independent model. Missing reads remain errors in the calculator checks.
