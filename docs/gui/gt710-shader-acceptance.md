# GT 710 shader upload and binding evidence

`GT710_SHADER` schema 1 records the eight triangle asset SHA-256 hashes, A197 class and subchannel, code address, segment size and offsets, GPR counts, upload read-backs, release receipt, trap register addresses and before/after words, error, and `draw: pending-7.4`. The scorer checks hashes against the retained 7.1 manifest and GPR counts against the retained shader JSON.

`GT710_SHADER_IMAGE` rows travel in the network artifact. Each row names a case, read-back poison, byte offset and hex bytes; `GT710_SHADER_BULK` on serial gives the rows' length and SHA-256. The four ordered cases are `Withheld`, `AfterWithheld`, `Flipped`, and `AfterFlipped`, each read twice with 0x55 and 0xaa read-back poisons. Withheld contains only 0x55, flipped differs from the independently assembled segment only at byte zero (bit zero), and both clean cases equal the segment. Each row and each serial read-back length and digest is checked against the complete bytes. This gate does not establish a draw; that is PR 7.4.
